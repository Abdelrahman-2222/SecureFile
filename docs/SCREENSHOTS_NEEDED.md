# Screenshots the author must supply (README, Step 6.4)

**Status: waiting for the user.** No screenshot was invented or generated. Take them from the real app, on a clean Windows
profile, and save them in `docs/images/` (create the folder) with these names. Then add the image lines to `README.md`
under "Screenshots" (for example `![Main window](docs/images/main-window-light.png)`), each with a short alt text.
Do not include real file names, paths or passwords in the pictures.

| File name | What to show | Notes |
|---|---|---|
| `main-window-light.png` | Empty main window, light mode | Windows 11, 100% scale |
| `main-window-dark.png` | Same, dark mode | Settings → Personalization → Colors |
| `encrypt-ready.png` | A test file chosen, password typed twice, strength bar visible, "Ready. Choose Encrypt file." | Use a dummy file such as `hello.txt`; mask nothing, the password dots are fine |
| `encrypt-success.png` | Green success message after encrypting | |
| `wrong-password.png` | The plain error after a wrong password | |
| `smartscreen.png` | "Windows protected your PC" with **More info** expanded and **Run anyway** visible | Take it in Windows Sandbox (Step 6.2) |
| `demo.gif` (optional) | 20-second flow: browse, encrypt, decrypt | Keep under 5 MB; ScreenToGif or the Xbox Game Bar |

Keep each PNG under about 300 KB (crop to the window).
